处理流程

- 入口命令行：运行 python main.py xxx.png ，解析参数 image_path 以及可选 --min-area 、 --max-area 、 --config 。
- 输入校验：检查 xxx.png 是否存在、可读、大小合理。失败则退出并打印错误。
- 初始化组件：创建 Config ，实例化 PolygonDetector （检测多边形）、 UniquenessAnalyzer （唯一性分析），并创建输出目录 Config.OUTPUT_DIR 。
- 多边形检测： PolygonDetector.detect_polygons(image_path) 返回所有联通体的多边形信息列表 polygons 以及原始图像 original_image 。
- 面积过滤（可选）：如命令行传入 --min-area/--max-area ，调用 UniquenessAnalyzer.filter_by_size 保留落在面积范围内的多边形。
- 唯一性分析：
  - 计算相似度矩阵： SimilarityCalculator.calculate_similarity_matrix(polygons) 生成 similarity_matrix （两两多边形的相似度，取值通常在 0~1，越大越相似）。
  - 计算唯一性评分： UniquenessAnalyzer.calculate_uniqueness_scores(polygons) ，对每个多边形用“1-相似度”构成的指标并加权平均（默认 0.7/0.3 组合最大/平均相似度）得到 uniqueness_scores 。
  - 选出最唯一： np.argmax(uniqueness_scores) 得到 most_unique_index 与对应 most_unique_score 。
- 坐标输出：对最唯一多边形取其边界框 bbox=(x,y,w,h) ，换算为两点坐标 top_left=(x,y) 与 bottom_right=(x+w, y+h) 。
- 可视化与保存（当 Config.SAVE_INTERMEDIATE_RESULTS=True 或启用可视化时）：
  - 叠加结果图：保存 *_result.png ，所有多边形绘制在原图上，最唯一者高亮。
  - 导出唯一联通体：将唯一多边形区域裁剪保存为 *_unique.png 。
  - 保存两个 JSON 报告： *_analysis.json （整体分析）与 *_report.json （最唯一多边形的详细原始字段）。
- 标准输出：在控制台打印“左上角/右下角坐标”、“唯一性评分”，以及一行标准化坐标输出。
JSON 文件与字段

- 文件 Config.OUTPUT_DIR/<图片名>_analysis.json
  - image : 输入图像文件名。
  - most_unique_index : 最唯一多边形在过滤后列表中的索引（整数）。
  - uniqueness_report : 唯一性分析的完整报告对象（见下）。
  - polygons : 过滤后的多边形列表（字段已序列化为基本类型）：
    - id : 多边形的唯一标识（整数）。
    - bbox : 边界框 [x, y, w, h] （整数）。
    - area : 面积（像素数，浮点）。
    - perimeter : 周长（像素长度，浮点）。
    - vertices : 顶点数（整数）。
    - aspect_ratio : 宽高比 w/h （浮点）。
    - extent : 外接矩形内的填充率 area/(w*h) （浮点）。
    - solidity : 凸包填充率 area/convex_hull_area （浮点）。
  - uniqueness_report 的详细字段（来自 UniquenessAnalyzer.get_uniqueness_report ）：
    - total_polygons : 参与分析的多边形数量（整数）。
    - uniqueness_scores : 每个多边形的唯一性评分列表（越高越独特）。
    - similarity_matrix : 相似度矩阵的二维列表， similarity_matrix[i][j] 表示第 i 与第 j 的相似度（0~1）。
    - most_unique_index : 最唯一多边形的索引（与上层字段一致）。
    - most_unique_score : 最唯一多边形的唯一性评分（浮点）。
    - similar_pairs : 相似度超过阈值的多边形对列表，每项为 (i, j, similarity) 。
    - analysis_summary : 文本摘要，含检测数量、相似对数量、最唯一索引与评分。
    - most_unique_polygon_info : 最唯一多边形的关键摘要字段：
      - id : 多边形标识。
      - bbox : 边界框 [x, y, w, h] 。
      - area : 面积。
      - vertices : 顶点数。
- 文件 Config.OUTPUT_DIR/<图片名>_report.json
  - 内容为“最唯一多边形”的原始信息快照，便于对该联通体做深入分析。包含但不限于以下字段：
    - id : 多边形标识。
    - bbox : 边界框 [x, y, w, h] 。
    - area : 面积。
    - perimeter : 周长。
    - vertices : 顶点数。
    - aspect_ratio : 宽高比。
    - extent : 填充率。
    - solidity : 凸包填充率。
    - contour : 原始 OpenCV 轮廓坐标数组（已转成普通列表以便 JSON 序列化）。
    - polygon : 近似后的多边形坐标数组（同样为列表）。
输出坐标与评分含义

- top_left : 最唯一多边形边界框左上角 (x,y) ，用于定位。
- bottom_right : 边界框右下角 (x+w, y+h) ，与 top_left 定义矩形区域。
- uniqueness_score : 该多边形的唯一性数值，综合考虑其与其他所有多边形的最大相似度与平均相似度；值越高表示越不相似（更独特）。
可能的特殊情况

- 未检测到多边形： uniqueness_report 中 total_polygons=0 ， most_unique_index=-1 ，评分为 0.0 ， analysis_summary 标注无多边形。
- 仅一个多边形：唯一性评分为 1.0 ，相似度矩阵退化为 [[1.0]] 。
